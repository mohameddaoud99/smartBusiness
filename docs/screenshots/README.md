# Screenshots

Drop the PNG/JPEG captures here under these exact names and the images in the project `README.md`
will resolve automatically (GitHub renders them inline on the repo page).

| File to save | What it shows |
|---|---|
| `dashboard.png` | Dashboard — sales/purchases/stock KPIs, 6-month charts, late invoices |
| `invoice.png` | An invoice: lines with delivered/left quantities, payments panel |
| `sales-orders.png` | Sales orders list |
| `stock.png` | Stock levels — in stock / reserved / available |
| `customers.png` or `suppliers.png` | Customers or suppliers list |
| `users-roles.png` | Roles & permissions (RBAC) screen |
| `audit-log.png` | Audit log — sign-ins, refused sign-in, who changed what |
| `print-preview.png` | The printed document sheet (invoice/quote/etc.) |

Any screenshot not saved here just shows as a broken image link in the README — harmless, but
worth filling in before sharing the repo.
